Google Chrome Remote Desktop Extension (google-chrome-remote-desktop-extension)

A lightweight Manifest V3 Chrome extension whose sole purpose is to synchronize and lock the window frame (title bar) color of the Google Chrome Remote Desktop Web App (https://remotedesktop.google.com/).

Background

By default, https://remotedesktop.google.com/ omits <meta name="theme-color"> from its HTML <head> and omits theme_color from /_/RemotingUi/manifest.json, causing Chrome to render the standalone PWA window with an unmatched default title bar.

In Auto (Match App Theme) mode (enabled by default), src/content.js automatically detects Chrome Remote Desktop's active Light/Dark theme (body.afF7cb, body.fv4cze, --page-bg-color, and localStorage['dark-mode$*']) as well as active modal dialog scrims (.llhEMd.iWO5td), keeping <meta name="theme-color"> and the manifest theme_color / background_color synchronized in real time:

Theme Base Header Color Dialog Open (50% Scrim)
Light #fafafa (rgb(250, 250, 250)) #7d7d7d (rgb(125, 125, 125))
Dark #212121 (rgb(33, 33, 33)) #111111 (rgb(17, 17, 17))

You can switch to manual mode at any time via the extension popup to pick a custom hex color or select one of the 4 preset swatches (#fafafa, #ffffff, #212121, #131314).

Installation (Unpacked Extension)

  1. Open chrome://extensions/ in Google Chrome.
  2. Enable Developer mode (top-right toggle).
  3. Click Load unpacked and select D:\Development\google-chrome-remote-desktop-extension (or click Reload (↻) if already loaded).
  4. Open the Chrome Remote Desktop web app (https://remotedesktop.google.com/access/) — the window frame automatically matches your active Light/Dark theme (#fafafa or #212121) and dims seamlessly when modal dialogs open, or can be overridden via the extension icon in the title bar.
